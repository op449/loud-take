# Loudtake — Ideas that don't scroll past.

Turnkey creator distribution engine for early-stage and venture-backed tech startups.

## Overview
Loudtake operates a high-velocity creator distribution engine combining human UGC testing scaled with generative AI.

- **Stack:** HTML5, Modern CSS (Instrument Serif + Inter), Vanilla JS
- **Design System:** Editorial Warm Ivory (`#F4F1EA`) & Pure Pitch Black (`#000000`)
- **Key Metrics:** 554K+ Organic Views, $1.97 Blended CPM, 501+ High-Intent Comments

## Local Development
Run a local static server:
```bash
python3 -m http.server 3000
```
Then visit `http://localhost:3000`.
